에이전트가 작업하는 동안은 깨어 있고, 끝나면 곧바로 잠듭니다.

메뉴 바에 위치한 작고 간결한 앱입니다. 클로드 코드, 코덱스, 올라마(Ollama) 또는 다른 AI 에이전트가 실행 중일 때는 뚜껑을 닫은 상태에서도 맥을 깨어 있게 유지합니다. 스마트 노슬립(Smart NoSleep)은 에이전트의 작업 종료를 감지해 자동으로 절전 모드로 전환하므로 배터리와 열 관리에 최적화되어 있습니다.

설치 파일과 정기적인 업데이트 소식을 받아보려면 이메일 주소를 입력하세요 — 스팸은 전혀 없습니다.

주요 기능

🤖
스마트 노슬립

밤새 이뤄지는 AI 코딩 작업을 위해 설계되었습니다: 에이전트가 활성 상태일 땐 깨어 있고, 유휴 상태로 전환되면 맥을 자동으로 절전 모드로 전환하며, 그 시점을 알려줍니다.

💤
뚜껑 닫은 상태에서도 깨어 있음

뚜껑을 닫은 상태에서도 깨어 있으며, 외부 디스플레이가 필요하지 않습니다.

🔋
배터리 안전 보호

배터리 잔량이 5%에 도달하면 절전 차단을 자동 해제하여 맥이 강제 종료되는 것을 방지합니다.

⌨️
단축키 하나로 제어

어디서나 ⌃⌘S를 눌러 깨어 있게 하거나 해제할 수 있으며, 메뉴 바 아이콘 클릭으로도 가능합니다.

⏱️
타이머 기능

15분, 1시간, 또는 2시간 동안만 깨어 있게 한 후 자동으로 해제합니다.

🪶
가볍고 효율적

일렉트론 없이 순수 Swift로 개발된 네이티브 앱. CPU 및 메모리 사용량은 거의 무시할 수 있을 정도로 미미합니다.

설치 방법

NoSleep은 오픈소스이며 유료 Apple 개발자 인증서로 서명되지 않았기 때문에, macOS에서 처음 실행할 때 '확인할 수 없음' 경고가 표시됩니다. 이는 정상적인 현상입니다. 터미널에서 한 번만 명령어를 실행하면 됩니다.

  1. 설치 프로그램을 다운로드하세요 — 기본적으로 Downloads 폴더에 저장됩니다.
  2. 터미널을 엽니다(응용 프로그램 → 유틸리티), 아래에 표시된 명령어를 복사해서 실행하세요.
  3. .pkg 파일을 두 번 클릭하면 이제 정상적으로 열립니다.
  4. 설치 마법사에 따라 진행하세요 — 설치 완료 후 NoSleep이 자동으로 실행됩니다.
xattr -d com.apple.quarantine ~/Downloads/NoSleep-Installer-1.1.11.pkg

사용 방법

  1. 깨어 있게 하거나 해제하려면 ⌃⌘S를 누르거나 메뉴 바 아이콘을 클릭하세요.
  2. 기본값인 스마트 노슬립, 절대 노슬립(Absolute NoSleep), 또는 타이머 중 하나를 선택하세요.
  3. 뚜껑을 닫습니다. AI 에이전트는 계속 실행되며, 나중에 뚜껑을 열면 작업 완료 시점을 확인할 수 있습니다.

자주 묻는 질문

뚜껑을 닫고 외부 모니터 없이도 작동하나요?

네. 바로 그 점이 이 앱의 핵심 기능입니다. 일반적인 깨어 있게 하는 도구들은 단순히 유휴 상태의 절전을 막을 뿐인데, NoSleep은 뚜껑을 닫는 즉시 발생하는 클램쉘 절전(clamshell sleep)까지 막아줍니다 — 아무것도 연결하지 않은 상태에서도 말이죠.

배터리를 완전히 방전시키나요?

아니요. 모든 모드에서 배터리 잔량이 5%에 도달하면 절전 차단을 자동 해제하고, 배터리가 25% 이상이 되거나 전원에 연결되면 다시 활성화됩니다. 스마트 모드는 또한 AI 에이전트가 유휴 상태에 진입하자마자 맥을 즉시 절전 모드로 전환합니다.

안전한가요? 왜 macOS 경고가 뜨나요?

MIT 라이선스 하에 완전히 공개된 오픈소스입니다 — 코드 전체를 직접 확인하실 수 있습니다. 경고는 유료 Apple 개발자 인증서로 서명되지 않았기 때문에 나타납니다. 단 하나의 xattr 명령어로 경고를 쉽게 제거할 수 있습니다.

관리자 권한이 필요한가요?

한 번만 필요합니다. 뚜껑을 닫은 상태에서 맥을 깨어 있게 하려면 pmset 명령어가 필요하며, 이는 처음 실행 시 관리자 암호를 요청합니다. 이후에는 자동으로 조용히 작동합니다.
