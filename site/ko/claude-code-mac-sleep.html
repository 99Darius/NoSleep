Mac이 절전 모드로 전환될 때 Claude Code가 종료되는 것을 막기

20분짜리 AI 에이전트 작업을 시작하고 커피를 마시러 노트북 뚜껑을 닫았다가 돌아오면, 세션이 이미 죽어 있습니다. Claude Code, Codex CLI, Cursor 에이전트, Ollama, Aider 등 모든 AI 코딩 도구에서 이 문제가 발생하는데, 이는 도구 탓이 아닙니다. macOS의 동작 방식 때문입니다.

왜 에이전트가 중단되는가

Mac이 절전 모드로 전환되면 모든 프로세스가 일시 중지됩니다. 네트워크 연결은 타임아웃되고, 에이전트의 API 스트림은 끊어지며, Mac을 깨운 후에도 대부분의 도구는 이전에 수행 중이던 단계를 재개할 수 없습니다. 뚜껑을 닫으면 즉시 절전 모드로 진입하고, 열린 상태로 두면 유휴 시간 초과 후 절전 모드로 전환됩니다. 어느 경우든 작업은 사라집니다.

사람들이 시도했지만 효과 없는 방법들

  • 시스템 설정 > '디스플레이가 꺼질 때 절전 모드 방지' 옵션은 전원 어댑터 연결 시에만 적용되며, 뚜껑을 닫는 클램셸 절전 모드는 막지 못합니다.
  • caffeinate나 Amphetamine은 화면을 켜두긴 하지만, 배터리 사용 중 뚜껑을 닫으면 작동하지 않습니다.
  • 노트북을 반쯤 열어놓은 채 들고 다니기. 실제로는 작동하지만, 매우 어색해 보입니다. 사실 NoSleep의 개발 계기는 바로 이 방법이었습니다.
  • tmux / nohup은 SSH 연결 끊김 시 프로세스를 유지하지만, 기기 자체가 절전 모드로 전환되는 상황에서는 무용지물입니다.

실제로 작동하는 해결책

Mac이 절전 모드로 전환되지 않도록 시스템 차원에서 명령해야 합니다(pmset disablesleep). 그러나 작업이 끝난 후 다시 절전 모드로 전환하지 않으면 밤새 계속 실행되어 배터리를 완전히 소진시킬 수 있습니다. NoSleep은 이 두 가지를 모두 처리합니다:

  1. ⌃⌘S 키를 누르세요. 스마트 NoSleep이 활성화됩니다.
  2. 뚜껑을 닫으세요. Claude Code는 계속 실행됩니다.
  3. NoSleep은 AI 에이전트 프로세스를 감시합니다. 프로세스가 15분 이상 유휴 상태일 경우(설정 가능), Mac을 절전 모드로 전환하고, 언제 어떤 작업이 실행되었는지 알리는 알림을 표시합니다.
  4. 배터리 잔량이 5%에 도달하면, 현재 모드와 관계없이 즉시 절전 모드로 전환됩니다.

스마트 모드에서 감지하는 에이전트는?

실행 중인 프로세스로 나타나는 모든 도구: claude, codex, cursor, ollama, aider, gemini 및 유사한 CLI 기반 에이전트입니다. 감지는 프로세스 이름을 기준으로 하므로, 직접 만든 스크립트도 이름을 지정하면 동작합니다. 자동 감지보다 확실한 제어를 원한다면 Absolute NoSleep 또는 고정 타이머를 사용하세요.

무료, 오픈소스, 계정 불필요

NoSleep은 MIT 라이선스로 제공되며, 네이티브 Swift로 작성된 앱으로 용량은 약 1MB입니다. 어떤 원격 분석(telemetry)도 포함하지 않으며, 서명되지 않은 앱입니다 — 첫 설치 시 다운로드 페이지에 설명된 대로 한 줄짜리 xattr 명령어를 실행해야 합니다.
