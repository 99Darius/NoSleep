Stop Claude Code from dying when your Mac goes to sleep

You kick off a 20-minute agent run, close the laptop to go make coffee, and come back to a dead session. Every AI coding tool has this problem — Claude Code, Codex CLI, Cursor agents, Ollama, Aider — because it isn't the tool's fault. It's macOS.

Why the agent stops

When a Mac sleeps, every process is frozen. Network connections time out, the agent's API stream breaks, and when you wake the Mac the tool usually can't resume the turn it was in. Closing the lid triggers sleep immediately; leaving the Mac open triggers it after your idle timeout. Either way the run is gone.

Things people try that don't work

  • "Prevent sleep when display is off" in System Settings only applies when plugged in, and doesn't stop clamshell sleep.
  • caffeinate or Amphetamine keep the screen on but don't survive a closed lid on battery.
  • Carrying the laptop around half-open. Works. Looks ridiculous. This is genuinely how NoSleep got started.
  • tmux / nohup keep the process alive across SSH disconnects, but not across the machine itself sleeping.

What actually works

The Mac has to be told not to sleep at the system level (pmset disablesleep) — and then told to sleep again when the work is done, or it'll run all night and flatten the battery. NoSleep does both:

  1. Press ⌃⌘S. Smart NoSleep is on.
  2. Close the lid. Claude Code keeps running.
  3. NoSleep watches for agent processes. When they've been idle for 15 minutes (configurable), it lets the Mac sleep and leaves a notification saying when and what was running.
  4. If the battery ever reaches 5%, it releases immediately regardless of mode.

Which agents does Smart mode detect?

Anything that shows up as a running process: claude, codex, cursor, ollama, aider, gemini, and similar CLI agents. Detection is by process name, so it also works with your own scripts if you tell it the name. If you'd rather not rely on detection, use Absolute NoSleep or a fixed timer.

Free, open source, no account

NoSleep is MIT-licensed, native Swift, about 1 MB, and has no telemetry. It's unsigned — there's a one-line xattr step on first install, explained on the download page.
